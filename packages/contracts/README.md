# Contracts v1

JSON Schema draft-07 files are the source of truth, consumed by AJV in Electron and jsonschema in Python. Unknown fields, unsupported versions/operations and non-finite numbers are rejected. Breaking changes require a new schema version. The TypeScript interfaces mirror these schemas; shared fixtures and real worker responses are checked on both sides.

Parameters use normalized energy units with ħ = 1. The static two-level result contains two ascending eigenvalues, which travel inline. The driven two-level evolution contract specifies an initial basis state, Schrödinger time grid and observables. Its result references a `quantum-data/v1` little-endian Float64 artifact: rows of time, P₀, P₁, σx, σy, σz, and real/imaginary parts of both state amplitudes. The result records shape, byte count and SHA-256. The optional model `source` object carries Layer-1 provenance IDs without tying either side to implementation-specific objects.
