# Contracts v1

JSON Schema draft-07 files are the source of truth, consumed by AJV in Electron and jsonschema in Python. Unknown fields, unsupported versions/operations and non-finite numbers are rejected. Breaking changes require a new schema version. The TypeScript interfaces mirror these schemas; shared fixtures and real worker responses are checked on both sides.

Parameters use normalized energy units with ħ = 1. The static two-level result contains two ascending eigenvalues, which travel inline. New results may additionally contain `stateAnalysis`: for a resolved gap, real normalized eigenvectors in the |0⟩, |1⟩ basis, populations, Bloch expectations and eigenpair residuals; for a gap at or below `1e-10 × max(1, |Δ|, |Ω|)`, only degeneracy status, gap and threshold. Old energy-only results remain valid and must not be presented as if they contain eigenstates. The driven two-level evolution contract specifies an initial basis state, Schrödinger time grid and observables. Its result references a `quantum-data/v1` little-endian Float64 artifact: rows of time, P₀, P₁, σx, σy, σz, and real/imaginary parts of both state amplitudes. The result records shape, byte count and SHA-256. The optional model `source` object carries Layer-1 provenance IDs without tying either side to implementation-specific objects.

`quantum-spectrum-study/v1` is a separate bounded orchestration plan for a static two-level eigenenergy sweep in Δ at fixed Ω (3–31 points). It composes existing verified `diagonalize` jobs, each with a durable `quantum-result/v1` run ID; cancellation takes effect between points. The corresponding `quantum-spectrum-study-result/v1` lists exact sampled coordinates and saved run IDs. It does not change the existing time-evolution `sweep` operation, whose output is final-state probability.
