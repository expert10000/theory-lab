# QVIS-016 observable workspace audit

Status: implemented for the currently reachable desktop result families.
`observable-workspace/v1` is a renderer projection, not a persisted job,
worker message, replacement inspector, or new source of scientific values.
Every card is tied to the active `scientific-selection/v1` coordinate and
matching run/model/operation. Reopened saved runs still require the existing
hash-verified path; reopening does not invent a sample selection.

| Saved result | Selected coordinate and available cards | Explicit boundary |
| --- | --- | --- |
| Two-level spectrum | Selected eigenenergy; stored resolved-state Bloch components and `P₁`; `Var(σz) = 1 − ⟨σz⟩²` derived from the stored expectation | At degeneracy or for legacy energy-only results, eigenstate expectations are unavailable. |
| Rabi, Landau–Zener, Stückelberg, strong drive | Selected stored time-row `P₀`, `P₁`, `⟨σx,y,z⟩`; derived Pauli-z variance | No claim about an unrecorded operator or another time row. |
| Jaynes–Cummings and Quantum Rabi | Selected population, mean photons, parity, cutoff-boundary occupation | The artifact does not store the full state vector. |
| Lindblad | Selected density-derived population, photons, purity, coherence, trace | The artifact does not store the full density matrix. |
| Transmon | Selected level in GHz; run-level stored charge `0↔1` matrix element | Selected-state charge expectation and eigenvector are unavailable. |
| Ising chain | Selected site's `⟨σᶻ⟩`, derived total `⟨Σσᶻ⟩`; selected low energy | All current v1 results lack pair expectations, so connected `Cᶻᶻᵢⱼ` is unavailable. No excited-state vector or universal finite-chain correlation length. |
| Final-population sweep | Selected grid cell's final `P₁` | A cell is not a saved trajectory. |
| SSH/QWZ | Selected stored SSH bands or edge density, or QWZ Berry curvature and optional supplied band | No generic eigenvector or inferred band value. |
| Hydrogenic orbital | Selected radial probability density or voxel `|ψ|²` derived from verified complex amplitudes | Radial and voxel coordinates are not interchangeable. |
| Oscillator family | Selected stored energy, position density, or time-row columns including quadrature moments/variance, occupation and diagnostics where present | No unrecorded wavefunction or column is generated by the cards. |

Cards use the conventions of their saved result: normalized energy with
`ℏ = 1` where applicable, Transmon GHz, hydrogenic `a₀`, and explicit
dimensionless/probability/photons labels. `stored`, `derived`, and
`unavailable` are distinct states. A numerical diagnostic is not a formal
uncertainty estimate; no statistical error bar is fabricated. The existing
inspectors remain authoritative for complete input, cutoff, convergence,
cache, engine and provenance detail.
