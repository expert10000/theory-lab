# QWZ result contract vertical slice (QI-02/03)

Theory Lab owns the `packages/contracts/schemas/quantum-result.v2.json` schema. The same schema is checked by AJV in TypeScript and the worker's finite-number JSON Schema validator in Python. The immutable saved `quantum-result/v1` bytes remain the source of numerical authority. Math3D consumes exported `quantum-scene/v1` bundles independently; it does not yet depend on this Lab-owned descriptor. This is the distribution boundary for the QWZ slice; broader run/link/study/cursor contracts need separate admission before cross-app use.

`quantum-result/v2` is currently a strict, additive descriptor for completed QWZ topology runs with supplied band arrays. It records source result SHA-256 and byte length, stable run/job IDs, model parameters, four typed datasets with roles, axes, shape, units, source JSON pointers and SHA-256 of little-endian Float64 values. It carries bulk/sampled gaps, Chern and mesh-resolution facts. Eigenstates and Berry connection are explicitly unavailable. It contains no numerical arrays and does not alter or rewrite a stored v1 run. `RunStore.resultV2(runId)` loads and verifies the exact saved run before constructing the descriptor.

The checked-in saved run `run-05ce1036d70c466eb4f900944a85c474` has result SHA-256 `01eb644e4a07df9f4aa6f49ce27a61a1e98d920aabd794962f57420ca2d2decf`. `packages/contracts/fixtures/qwz-result.v2.json` is a cross-language golden output. The TypeScript and Python tests regenerate it, refuse changed source bytes or descriptor fields, and compare the four datasets against two scenes emitted from that same run. The generated curvature and both band-energy binary hashes match the previously pinned Math3D QWZ examples. Scene JSON differs because the saved run ID, timestamp and result hash differ; the older result payload is not available.

Reproduce the scene pair with `npx tsx scripts/export-qwz-baseline.ts <existing-directory>`. Math3D's `tests/fixtures/quantum-qi01` contains this exported pair and its independent import gate. The existing `quantum-scene/v1|v2` readers and `quantum-result/v1` persistence stay in place. Further result models, external binary storage, package distribution and editable cross-app study/cursor contracts are outside this first QWZ admission.
