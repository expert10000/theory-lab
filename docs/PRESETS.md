# Volume VIII reference presets

QLAB-015 pins six runnable desktop configurations to `expert10000/theory` revision [`434e29b4ed7d412a9cee6aa2853bb933fc872494`](https://github.com/expert10000/theory/tree/434e29b4ed7d412a9cee6aa2853bb933fc872494/examples/python/qutip). These are source-linked parameter sets, not a runtime import or a claim that every example in that tree is implemented here. Opening a card loads an existing laboratory. Its job carries `sourceRepository`, `sourceModule`, `volume`, and `exampleId`; the worker echoes that model source in the result. Users may edit the controls afterward, but the pinned analytic pass/fail check applies only to the exact preset.

Numerical checks use a maximum absolute error threshold of `10⁻³` across all saved samples. QuTiP and native jobs share the same contract and source metadata. The Electron end-to-end smoke runs all six cards through the real worker; unit tests verify contract validity, pinned links, exact-configuration gating, and that perturbed curves fail the check.

Chapter 58–59 files in the local Volume VIII checkout are architecture placeholders; these presets refer to the separate inspected QuTiP example tree at the pinned revision. The app does not present unmatched Floquet, Stückelberg, full quantum-Rabi, thermal-oscillator, or coherent-cavity examples as completed presets.
