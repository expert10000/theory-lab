**Started 26 November 2026.** This is a new feature track. The [Math3D consumer plan](https://github.com/expert10000/Math3D/blob/main/docs/quantum-ute2-study-roadmap.md) governs the second app. Neither document changes the frozen Math3D 2.0 release scope, QI-40 pair gate, or later memory qualification.

## Journey and evidence boundary

1. **Read the evidence.** Show the October 2026 ultrasound results as reported thermodynamic evidence for competing order parameters and a fluctuation regime. Attribute phase-locking and short-stiffness interpretations to their authors. The [tetracriticality article](https://doi.org/10.1038/s41567-026-03504-z) and [phase-stiffness article](https://doi.org/10.1103/qjt6-hj2k) are the primary sources. The chapter's §§1, 9–10 (PDF pp. 2, 7) set the interpretation boundary.
2. **Explore competition.** Run the dimensionless, uniform two-component Landau free energy of chapter §8, Eqs. 18–21 (PDF p. 6). Show normal, pure SC1, pure SC2, and stable mixed minima, with the actual Hessian/stability result. Use chapter §12.1 (PDF p. 8) as a reference case. A temperature/pressure control can vary declared phenomenological coefficients; it must not display a measured UTe2 phase boundary without licensed, pinned experimental data and a fit.
3. **Inspect quasiparticles.** Start with the pedagogical 2×2 BdG sector of chapter §5.1, Eqs. 13–14 (PDF p. 4), including electron/hole weights and gap closure. Then add the chapter §6.1 square-lattice p_x/p_y mixture as a separate toy model. Explicitly distinguish energy eigenvalues, order-parameter amplitudes, and pairing phase. A spinful D2h candidate requires its own symmetry and basis review before any 4×4 or multiorbital claim.
4. **Test conditional topology.** On the chapter §11 class-D square-lattice model (PDF pp. 7–8), compute a bulk gap before a Chern number, report mesh convergence and orientation convention, and withhold an invariant at a gap closing. Only after that should an open-boundary toy calculation test edge localization. No calculated toy invariant is evidence of UTe2 Majorana modes; chapter §13 (PDF p. 9) lists the missing material-specific observations.
5. **Open the same run in Math3D.** Export exact, versioned scene bundles with immutable run/result hashes, parameter units, grid coordinates, gap/phase masks, model-class labels, numerical tolerances, and explicit omissions. Math3D verifies and renders the supplied arrays as a Project Study; it does not solve or certify superconductivity. A source mutation must withhold all derived values. See the [consumer plan](https://github.com/expert10000/Math3D/blob/main/docs/quantum-ute2-study-roadmap.md).
