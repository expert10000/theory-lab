# Hamiltonian Atlas and pre-3D topology labs

Theory Lab vendors a read-only snapshot of 68 Hamiltonian Atlas entries from
`expert10000/theory` revision `48e2036ba7c7dd5c79d54749341a79d41770cbb7`.
`packages/atlas/atlas.v1.json` is generated by `node scripts/sync-atlas.mjs <theory-checkout>`.
The source Atlas marks every entry's adapter and runnable fields `null`; the
desktop never treats those fields as an implementation claim. It exposes
separate, tested Theory Lab bindings for compatible subspaces only.

R1 also vendors seven source-side adapter/example references, with Git paths
checked at that revision. Their direct/family/reference_lab kinds are not Lab
execution permissions or new numerical acceptance evidence. The nine existing
Lab bindings remain unchanged. Both desktop/web Atlas inspectors show reference,
source-example, Lab-binding and saved-scene capabilities separately.
See [the complete R1 map](ATLAS_RECONCILIATION_R1.md) for all 68 entries,
typed implementation modules, related-but-unbound physics and genuine gaps.
The app never fetches live source metadata or executes runner paths from it.

## Numerical definitions and limitations

The SSH Bloch Hamiltonian uses `q(k)=t₁+t₂ exp(i k)` and energies ±|q|.
Winding is 1 for |t₂|>|t₁|, 0 otherwise, and undefined when the bulk gap
`2||t₁|-|t₂||` closes. A separate 2N×2N open-chain eigensolve gives the
mid-spectrum pair and its site density. This is a finite-size edge diagnostic,
not proof of an exactly zero-energy state at finite N.

The QWZ Hamiltonian is `sin(kx)σx+sin(ky)σy+(m+cos(kx)+cos(ky))σz`.
The occupied lower-band Chern number is computed with normalized eigenvector
links and plaquette phases (Fukui–Hatsugai–Suzuki), on a periodic momentum
grid. The mass-sign phase diagram independently checks whether that mesh
resolves the phase; a disagreeing raw lattice integer is labelled unresolved.
An independent analytic lower-band Berry-curvature formula is integrated
by midpoint quadrature; its deviation from the mass-sign value is shown as a
grid convergence diagnostic. The bulk gap is `2 min(|m+2|,|m|,|m−2|)`. At
`m=−2,0,2`, both invariant and curvature map are reported undefined.

This is a 2D lattice model, not a 3D Weyl solver. Chapter 62 illustrative
figure generators are not used as numerical validation. Tests cover SSH
dimerization, edge splitting and gap closure; QWZ Chern phases, critical
masses, mesh convergence and the 64 KiB worker protocol limit. Both labs use
the existing versioned job/result contracts, Electron supervisor, saved runs,
CSV/SVG/manifest exports and workspace snapshots.
